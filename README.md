# 🏙️ ГеоИнтеллект — веб-сервис анализа городской инфраструктуры

Лабораторная работа «Геоинтеллектуальный веб-сервис анализа городской инфраструктуры»:
интерактивная карта (**Leaflet + OpenStreetMap**, современная тёмная AI-console тема)
с объектами Басманного района Москвы и **ИИ-ассистент (YandexGPT)**, отвечающий
на вопросы о пространственных данных.

## Возможности

- ✅ Интерактивная карта (масштабирование, перемещение)
- ✅ 26 реальных объектов 5 типов: школы, поликлиники, парки, остановки, вузы/библиотеки
- ✅ Popup с атрибутами при клике на объект
- ✅ Выбор объекта → вопрос на естественном языке → ответ ИИ
- ✅ Прокси-сервер Express скрывает токены Yandex Cloud от браузера
- ✅ Формирование контекста: ближайшие N объектов + выбранный объект + центр карты
- ✅ Обработка ошибок: пустой вопрос, неверный/просроченный токен, лимит запросов (429), таймаут
- ⭐ Доп.: фильтры типов (чекбоксы)
- ⭐ Доп.: подсветка объектов, упомянутых ИИ (+ чипы с кликом и круг радиуса анализа)

## Архитектура

```
Браузер (Leaflet)  ──POST /api/ask──▶  Прокси (Express, :3000)  ──HTTPS──▶  YandexGPT API
     │                                     │                                   llm.api.cloud.yandex.net
     │  GET data.json, GET /                │  Api-Key / Bearer IAM-токен
     └──────────────────────────────────────┘  (ключи хранятся ТОЛЬКО в .env на сервере)
```

Демо-режим: если ключи не заданы, сервер включает **локальный демо-анализатор**
(правила + формула гаверсинуса) — приложение полностью работает без ключей,
что удобно для демонстрации и отладки.

## Быстрый старт

```bash
# 1. Установить зависимости (Express)
npm install

# 2. (Пере)собрать данные из OpenStreetMap — опционально, данные уже в data/data.json
npm run fetch:osm     # выгрузка через Overpass API
npm run build:data    # сборка data/data.json

# 3. Настроить ключи Yandex Cloud (можно пропустить → будет демо-режим)
cp .env.example .env
#   заполните YC_FOLDER_ID и YC_API_KEY (или YC_OAUTH_TOKEN)

# 4. Запустить
npm start
# открыть http://localhost:3000
```

> **Node.js**: требуется ≥ 18. Локальный портативный рантайм `node-runtime/`
> в репозиторий не включается (он во `.gitignore`). Используйте системный `node`
> или скачайте его самостоятельно.

## Русские карты (опционально)

Если нужен Яндекс.Карты вместо OpenStreetMap, получите ключ в кабинете
разработчика Яндекс и добавьте в `.env`:

```env
YANDEX_MAPS_API_KEY=ваш_ключ
```

Без ключа используется OpenStreetMap — бесплатно и без регистрации.

## Ключи Yandex Cloud

1. Консоль Yandex Cloud → **Service YandexGPT** → **API-ключи** → создать ключ →
   `YC_API_KEY=...`
2. Folder ID каталога → `YC_FOLDER_ID=...`
3. Альтернативы (см. `.env.example`):
   - `YC_OAUTH_TOKEN` — прокси сам обменяет его на IAM-токен и будет
     автоматически обновлять (IAM живёт 12 часов);
   - `YC_IAM_TOKEN` — готовый токен, но вручную (живёт 12 часов).

Какие парки есть рядом с этой поликлиникой?
Какая поликлиника ближе всего к выбранному объекту?
